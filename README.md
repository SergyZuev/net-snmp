# Обновление net-snmp 5.9.4 → 5.9.5

Пакет подготовлен для вашей кастомной CMake-раскладки (компоненты netsnmp / netsnmpagent / netsnmpmibs / snmpnetstat).

## Состав пакета

- **265 обновлённых файлов** в вашей раскладке — содержимое из upstream v5.9.5, пути сопоставлены с вашей структурой. Просто скопируйте поверх соответствующих файлов в репозитории.
- `netsnmp/include/net-snmp/net-snmp-config.h.in` — обновлённый шаблон (нетронутый upstream, заменяется целиком).
- `CONFIG_H_MERGE_GUIDE.md` — точечные правки для вашего кастомного `net-snmp-config.h` (**не перезаписывать целиком!**).
- `CMAKELISTS_VAR_ADDITIONS.md` — 3 строки, которые нужно добавить в `netsnmp/CMakeLists.var`.

## Что НЕ вошло в пакет (обоснованно)

- **MIB-файлы** (`LM-SENSORS-MIB.txt`, `SNMP-TLS-TM-MIB.txt`, `rfclist`): компонент `netsnmpmibs` собирает библиотеку из исходников агента, но ни один MIB-текст не зарегистрирован в сборке. Изменения этих файлов на вашу сборку не влияют — пропущены.
- **win32, perl, testing, ci, man, configure.d** и прочие upstream-каталоги вне вашей раскладки — не переносятся.
- **Ваш кастомный `net-snmp-config.h`** — обрабатывается вручную по guide, чтобы сохранить платформенные настройки.
- **cmake/, nuget/, BUILD.md, корневые CMakeLists** — ваши служебные файлы, не трогаются.

## Порядок применения

1. Скопируйте 265 файлов из этого пакета поверх файлов в вашем репозитории (пути совпадают).
2. Внесите правки в `netsnmp/include/net-snmp/net-snmp-config.h` по `CONFIG_H_MERGE_GUIDE.md` (5 пунктов).
3. Добавьте 3 строки в `netsnmp/CMakeLists.var` по `CMAKELISTS_VAR_ADDITIONS.md`.
4. Проверьте дифф (`git diff`) — убедитесь, что изменены только ожидаемые файлы.
5. Соберите все компоненты. Особое внимание — компиляции `netsnmp` (проверка config.h).
6. Закоммитьте с сообщением `Update net-snmp 5.9.4 -> 5.9.5`, поставьте тег `v5.9.5`.

## Ключевые изменения upstream 5.9.5

- **snmptrapd**: исправлена критическая уязвимость (крах на специально сформированном трапе) — основная причина обновления.
- **snmpd**: dskTable динамический при includeAllDisks; добавлена ФС ubifs.
- **configure**: путь OpenSSL по умолчанию изменён с `/usr/local/ssl` на `/usr` (на вашу CMake-сборку не влияет, пути задаются явно).
- Чистка избыточных объявлений (-Wredundant-decls), мелкие фиксы сборки.
- Новые системные заголовки: freebsd15/16, openbsd8.

## Validация

Патч из 265 файлов был проверен на макете вашего дерева (upstream 5.9.4 в вашей раскладке) — применяется чисто, без конфликтов. Локальных модификаций исходников не обнаружено (хеши совпали с upstream, git log содержит только коммиты обновления cmake-скриптов).
